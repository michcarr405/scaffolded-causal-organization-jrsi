# RC4 network-enabled clean-installation check

The GitHub Actions workflow `.github/workflows/rc4-clean-room.yml` runs on a fresh `ubuntu-latest` runner with Python 3.13. It installs only `requirements.txt`, validates repository and file manifests, runs pytest, verifies recovered-campaign manifests, exercises portable recovered runners in non-destructive modes, and performs a complete rerun of the short original catalytic prospective assay from the canonical campaign.

A successful workflow run should be retained with its commit SHA and logs as the final RC4 installation record.
