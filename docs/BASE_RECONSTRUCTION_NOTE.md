# RC3.1 base reconstruction note

The previously generated monolithic RC3 ZIP was not mounted in the current execution runtime. RC3.1 was therefore reconstructed from the controlling cold-start archive, canonical source bundle, verified recovery patch, and verified computational/figure artifacts available in the project runtime. Original campaign trees are copied directly from those frozen archives; recovered campaign trees come directly from the verified recovery patch.

This reconstruction does not recreate missing scientific provenance: the original archived production trees are preserved under `provenance/`. Public portability copies are distinct derivatives and are explicitly documented.


The working manuscript and Supplement PDFs were removed from the RC4 candidate by explicit author decision. They are not part of the computational release artifact and will be audited externally at RC5.
