# Manuscript exclusion policy

The JRSI manuscript and Supplement are intentionally excluded from the public computational repository. They remain editable publication documents until submission.

The repository contains the frozen computational evidence required to support them: code, configurations, seed ledgers, simulation outputs/evolved states where retained, validation and provenance records, processed source tables, and source-faithful publication-figure builders/assets.

RC5 is an external manuscript-to-repository consistency audit. The final polished manuscript does not need to be embedded in the repository for that audit.

This separation prevents a working manuscript draft from being mistaken for an immutable component of the reproducibility release.
