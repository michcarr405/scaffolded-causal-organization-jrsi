# Catalytic-Complex Scaffolded Causal Organization v1.0.0

This package contains a substantially different microscopic realization of the reduced Scaffolded Causal Organization theory.

The model is nonspatial and nonsequence-based. Protocells inherit compositions of catalytic dimers. An external reaction-field asymmetry biases four essential reaction channels. Selection can reorganize inherited dimer composition. Relation-specific intervention preserves monomer marginals while randomly re-pairing monomers, allowing the causal contribution of inherited complex identity to be isolated.

`discovery/` contains the exploratory parameter campaign, retrieval/anisotropy assays, and six-matrix ensemble test.

`confirmatory/` contains the prospectively frozen plan, independent catalytic matrix, 30 new paired root blocks, result freeze, figures, endpoint states, scripts, and hashes.

All six prospectively frozen primary confirmatory criteria passed.
