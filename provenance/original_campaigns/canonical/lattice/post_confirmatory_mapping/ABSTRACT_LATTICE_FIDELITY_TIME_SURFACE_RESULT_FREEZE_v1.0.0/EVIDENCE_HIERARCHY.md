# Evidence hierarchy — abstract lattice control

## Two campaigns, two evidentiary jobs

The correct structure is:

**Older lattice campaign = confirmatory existence test.**

**New dense campaign = post-confirmatory mechanistic mapping.**

They answer different questions, and their independence is scientifically valuable.

The original frozen `ABSTRACT_LATTICE_CONFIRMATORY_v1.0.0` prospectively established four qualitative signatures on fresh root blocks:

- scaffold-specific acquisition;
- fidelity dependence;
- acquisition-expression separation;
- equal-distance anisotropic retrieval.

That campaign remains the canonical evidence that these predictions were **independently confirmed**.

The new dense campaign then resolves the mechanism at higher temporal and fidelity resolution:

`DeltaV_rel = f(p,t)`,

including fidelity-response shape, acquisition timescale, generation-50 stability, transient history specificity, and the temporal relationship between relational causal value and fitness differentiation.

The evidence sequence is therefore:

`discovery -> prospective confirmation -> independent mechanistic mapping`.

Discarding or silently replacing the confirmatory dataset would erase this sequence and weaken provenance.

## Canonical evidence by claim

| Claim | Canonical evidence |

| Scaffold-specific acquisition exists | original confirmatory campaign |
| Fidelity dependence exists | original confirmatory campaign; independently refined by new mapping |
| Shape of fidelity dependence | **new mapping campaign** |
| No support for an abrupt threshold among the three prespecified candidate shape models | **new mapping campaign** |
| Acquisition-expression separation exists | original confirmatory campaign |
| Temporal development of acquisition-expression separation | **new mapping campaign** |
| Equal-distance anisotropy exists | original confirmatory campaign |
| Temporal development of anisotropy | **new mapping campaign** |
| History-specificity temporal profile | **new mapping campaign** |
| Generation 50 approximates stable `DeltaV_rel` amplitude at the six tested sentinels | **new mapping sentinel arm** |
| `DeltaV_rel` and `DeltaF` have near-coincident dynamics in the abstract lattice | **new mapping campaign** |

## Replacement rule

**New data supersede old estimates where resolution improved; they do not supersede the old confirmation.**

For manuscript visualization, the new campaign should generally replace the older sparse fidelity curve, coarse temporal trajectories, threshold-like descriptive language, and endpoint-only timing descriptions. The text or provenance note should still identify the older frozen campaign as the independent prospective confirmation of the four qualitative signatures.
