# Seed independence audit v1.0.0

This campaign uses a new SHA256 namespaced seed identity:
`CATALYTIC_COMPLEX_SCAFFOLD_STRENGTH_CONFIRMATORY_v1.0.0|<derivation-tag>`.

The original catalytic confirmation used small scalar seeds based on ROOT0=2000000. The new campaign uses deterministic 128-bit entropy values derived from unique campaign-specific tags and therefore does not reuse any original scalar seed identity.

The exact seed ledger of the earlier catalytic 18-point fidelity campaign is not currently recoverable from active Sources/File Library. Numeric value-by-value exclusion against that inaccessible ledger is therefore not possible. The present campaign nevertheless uses a new derivation namespace and no seed tag or scalar seed from any accessible catalytic source. This limitation is recorded prospectively rather than hidden.
